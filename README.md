# สื่อการสอนวิทยาศาสตร์และห้องแล็บเสมือน

โปรเจกต์สื่อการเรียนรู้วิทยาศาสตร์ภาษาไทย เน้นบทเรียนและแล็บจำลองที่เปิดจากไฟล์ HTML ได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

## หน้าที่มีในโปรเจกต์

- [สารบัญหลักสูตรเคมี ม.1–ม.6](index.html) — ค้นหาและกรองรายการตามระดับชั้น การ์ด ม.1 (เล่ม 2) และ ม.4 เปิดบทเรียนได้
- [เคมี ม.4 ครบ 6 บท](chemistry-m4.html) — แต่ละบทมีการ์ดเนื้อหา แบบทดสอบพร้อมเฉลยอธิบาย และการทดลองเสมือนแบบโต้ตอบ
- [ต้นแบบทักษะปฏิบัติการเคมี ม.4](chemistry-m4-lab.html) — บทเรียนต้นแบบเดิมเรื่องความปลอดภัย การเลือกอุปกรณ์ การอ่านเมนิสคัส และแบบทดสอบ
- [วิทยาศาสตร์ ม.1 เล่ม 2 · สารบัญการทดลองเสมือน](sci-m1-v2.html) — ห้องทดลองเสมือนครบ 18 กิจกรรมตามหนังสือเรียน สสวท. พร้อมกิจกรรมท้ายบท 4 อัน (`sci-m1-v2-final-<หน่วย>-<บท>.html`) หน่วยที่ 5 พลังงานความร้อน (5.1–5.8 เช่น [5.4 ความร้อนทำให้สารเปลี่ยนสถานะ](sci-m1-v2-lab-5-4.html)) และหน่วยที่ 6 กระบวนการเปลี่ยนแปลงลมฟ้าอากาศ (6.1–6.10) ไฟล์ละกิจกรรมชื่อ `sci-m1-v2-lab-<เลข>.html` ค่าที่ผู้จัดทำสมมติและแนวคำตอบที่หนังสือไม่มีเฉลยระบุไว้ในแต่ละหน้า ควรให้ครูตรวจก่อนใช้สอน
- [ระบบสุริยะ ม.3](solar-system-m3.html) — สื่อการเรียนรู้เดิมในโฟลเดอร์

## บทเรียนเคมี ม.4

1. ความปลอดภัยและทักษะในปฏิบัติการเคมี — ทดลองวัดปริมาตรซ้ำด้วยเครื่องมือต่างชนิด แล้วเปรียบเทียบค่าเฉลี่ยและการกระจาย
2. อะตอมและสมบัติของธาตุ — กระตุ้นอะตอมจำลอง อ่านความยาวคลื่นและพลังงานของสเปกตรัม
3. พันธะเคมี — สร้างแบบจำลอง H₂O, NH₃, CH₄ และ CO₂ เพื่อเปรียบเทียบรูปร่างและขั้ว
4. โมลและสูตรเคมี — ให้ความร้อนผลึกไฮเดรตจำลองจนมวลคงที่ แล้วคำนวณอัตราส่วนโมล
5. สารละลาย — คำนวณและเตรียมสารละลาย NaCl จากสารละลายตั้งต้นด้วย C₁V₁=C₂V₂
6. ปริมาณสัมพันธ์ — ปรับสารตั้งต้นในปฏิกิริยา NaHCO₃ กับกรดซิตริก แล้วหาสารกำหนดปริมาณและผลได้

### เปิดใช้งาน

เปิด `index.html` แล้วเลือกบท ม.4 หรือเปิด `chemistry-m4.html` โดยตรง ทุกหน้าเป็น HTML/CSS/JavaScript ในเครื่อง ไม่โหลดไลบรารี แบบอักษร หรือรูปจากเครือข่าย (ยกเว้น `solar-system-m3.html` ที่โหลด Google Fonts และการกดส่งคะแนนที่ส่งข้อมูลไป Google Apps Script) ความคืบหน้าจะบันทึกใน localStorage ของเบราว์เซอร์และอุปกรณ์นั้น

ทุกหน้าของ ม.1 เล่ม 2 และหน้าเคมี (`index.html`, `chemistry-m4*.html`) มีลายน้ำและเครดิต "จัดทำโดย ครูเก๋ วิจิตรา จิตสุภา" ใส่ด้วย `python3 tools/inject_site_meta.py` (รันซ้ำได้ ต้องรันใหม่ทุกครั้งที่เพิ่มหน้า `sci-m1-v2*.html`)

## การส่งคะแนนเข้า Google Sheet (หน้ากิจกรรม ม.1 เล่ม 2 และหน้าเคมี ม.4)

นักเรียนกรอกชื่อ เลขที่ ชั้น ห้อง แล้วกดส่งคะแนนรวมของกิจกรรมนั้น ข้อมูลไปที่ Google Apps Script ของครู แท็บแยกตามกิจกรรม (หน้าเคมี ม.4 แยกเป็น "เคมี ม.4 บทที่ 1–6" ตามแบบทดสอบของแต่ละบท และ "เคมี ม.4 ปฏิบัติการเบื้องต้น" สำหรับหน้า `chemistry-m4-lab.html` ส่วนหน้า ม.2–ม.3 และระบบสุริยะไม่มีการส่งคะแนน)

- `tools/apps_script/Code.gs` โค้ดฝั่งชีต (วางใน Extensions → Apps Script แล้ว Deploy เป็น Web app; **แก้โค้ดแล้วต้อง Deploy เป็นเวอร์ชันใหม่**) รายการกิจกรรมที่รับสร้างจาก `tools/build_curriculum.py`
- `tools/submit_config.json` เก็บ Web app URL (ว่าง = ซ่อนแผงส่งคะแนน)
- `tools/submit_module.js` โมดูลฝั่งเว็บ แต่ละหน้าเรียก `LabScore.set('ชื่อส่วน', ได้, เต็ม)`
- **ข้อเขียน:** ทุกช่องพิมพ์คำตอบ (textarea) ในหน้าถูกส่งไปแท็บ `ข้อเขียน` ซึ่งเป็นตารางข้อมูล แถวละหนึ่งคำตอบ (รหัสส่ง, ชื่อ, เลขที่, ชั้น, ห้อง, กิจกรรม, รหัสข้อ, คำถาม, คำตอบ) พร้อมคอลัมน์ `คะแนนที่ได้`, `คะแนนเต็ม`, `ผู้ตรวจ/หมายเหตุ` ที่เว้นว่างรอครูกรอก คอลัมน์ `รหัสส่ง` เชื่อมกับแถวในแท็บกิจกรรม ซึ่งมีคอลัมน์ `จำนวนข้อเขียน` และ `คะแนนข้อเขียน` (ว่าง) ด้วย ข้อเขียนไม่นับในคะแนนรวมของแผงส่งผล
- เป็นเว็บสาธารณะ ใครรู้ URL ก็ส่งได้ และคะแนนคำนวณในเบราว์เซอร์ จึงเหมาะกับแบบฝึกหัด ไม่ใช่การสอบตัดเกรด

## คำสั่งสำหรับผู้ดูแล

ทุกครั้งที่เพิ่ม/แก้ชื่อหน้า sci-m1-v2*.html ให้รันตามลำดับ:

```bash
python3 tools/build_curriculum.py      # สร้าง assets/curriculum-m1v2.js และรายการ id ใน Code.gs
python3 tools/inject_site_meta.py      # ฝัง meta แชร์ลิงก์ ลายน้ำ ธีม Apple และโมดูลส่งคะแนน
```

ธีมปุ่มและตัวหนังสืออยู่ที่ `tools/apple_theme.css` (ฝังทุกหน้า รวมหน้าเคมี) รองรับโหมดสว่างเท่านั้น
