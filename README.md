# สื่อการสอนวิทยาศาสตร์และห้องแล็บเสมือน

โปรเจกต์สื่อการเรียนรู้วิทยาศาสตร์ภาษาไทย เป้าหมายคือทำบทเรียนและการทดลองเสมือนที่เปิดจากไฟล์ HTML ได้โดยไม่ต้องต่ออินเทอร์เน็ต

## ต้นแบบที่มี

- [บทเรียนเคมี ม.4: ความปลอดภัยและทักษะในปฏิบัติการเคมี](chemistry-m4-lab.html) — บทเรียนโต้ตอบเรื่องการเลือกอุปกรณ์ ความปลอดภัย การอ่านเมนิสคัส และแบบทดสอบ ความก้าวหน้าเก็บไว้ในเบราว์เซอร์เครื่องนั้น
- [ระบบสุริยะ ม.3](solar-system-m3.html) — สื่อการเรียนรู้เดิมในโฟลเดอร์

### เปิดใช้งาน

ดาวน์โหลดไฟล์ `chemistry-m4-lab.html` แล้วเปิดด้วยเว็บเบราว์เซอร์สมัยใหม่ได้โดยตรง เนื้อหา สไตล์ ภาพจำลอง และสคริปต์อยู่ในไฟล์เดียว ไม่มีการโหลดทรัพยากรจากเครือข่าย ความก้าวหน้าจะบันทึกใน `localStorage` ของเบราว์เซอร์นั้น

## แผนบทเรียนเคมีเบื้องต้น

โครงร่างนี้ใช้สำหรับวางแผนผลิตสื่อ ไม่ใช่สารบัญทางการของโรงเรียน ต้องตรวจเทียบกับตัวชี้วัดและหนังสือเรียนที่สถานศึกษาใช้ โดย ม.1–ม.3 เป็นหัวข้อเคมีในวิทยาศาสตร์พื้นฐาน ส่วน ม.4–ม.6 เป็นรายวิชาเคมีเพิ่มเติม

| ระดับ | จำนวนบท | หัวข้อเบื้องต้น |
|---|---:|---|
| ม.1 | 5 | สารและสมบัติของสาร; สถานะและการเปลี่ยนสถานะ; สารบริสุทธิ์และสารผสม; การแยกสาร; อนุภาคของสาร |
| ม.2 | 5 | ธาตุและสารประกอบ; โครงสร้างอะตอมเบื้องต้น; การละลาย; สารละลายและความเข้มข้นเบื้องต้น; การเปลี่ยนแปลงทางกายภาพและทางเคมี |
| ม.3 | 6 | ปฏิกิริยาเคมี; สมการเคมีเบื้องต้น; กรด–เบสและตัวบ่งชี้; วัสดุและพอลิเมอร์; สารเคมีในชีวิตประจำวันและความปลอดภัย; เคมีกับสิ่งแวดล้อม |
| ม.4 | 6 | ความปลอดภัยและทักษะปฏิบัติการ; อะตอมและสมบัติของธาตุ; ตารางธาตุ; พันธะเคมี; โมลและสูตรเคมี; สารละลาย |
| ม.5 | 5 | แก๊ส; ปริมาณสัมพันธ์; อัตราการเกิดปฏิกิริยา; สมดุลเคมี; กรด–เบสและบัฟเฟอร์ |
| ม.6 | 5 | ไฟฟ้าเคมี; เคมีอินทรีย์; พอลิเมอร์; เคมีอุตสาหกรรม; เคมีในชีวิตประจำวันและโครงงาน |

รวม 32 บทในรายการตั้งต้น หัวข้อและการแบ่งระดับอาจปรับตามหลักสูตรสถานศึกษาและลำดับหนังสือเรียน

## แผนพัฒนาต่อ

1. เทียบโครงร่างกับหลักสูตรและหนังสือเรียนจริง แยกผลการเรียนรู้และตัวชี้วัดรายบท
2. ทำ storyboard และต้นแบบกิจกรรมให้แต่ละบทมีเป้าหมาย เนื้อหา การจำลอง แบบฝึก และเกณฑ์ผ่าน
3. ทดลองใช้รูปแบบต้นแบบกับครู/นักเรียน แล้วปรับความถูกต้อง ความเข้าใจง่าย และการใช้งานบนมือถือ
4. ผลิตบทเรียนตามลำดับชั้น ตรวจทานเนื้อหาและความปลอดภัย แล้วจัดทำเป็นเว็บ HTML แบบ offline
