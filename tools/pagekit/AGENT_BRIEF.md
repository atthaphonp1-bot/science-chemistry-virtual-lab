# AGENT_BRIEF: สร้างหน้าแล็บด้วย pagekit (ให้ใช้แทนการอ่านหน้าเก่าซ้ำ)

เป้าหมาย: เขียนแค่ **เนื้อหา** (`content.js`) กับ **ห้องทดลองเฉพาะ** (`labs.js`) ส่วนโครงหน้า/แท็บ/อ่านก่อนทดลอง/แบบทดสอบ/แบบฝึกหัด/ฟอร์ม/คะแนน/CSS มาจาก `tools/pagekit/` ห้ามเปิดหน้าเก่ามาลอกโค้ดเครื่องยนต์ ถ้าต้องดูตัวอย่างให้เปิด `tools/pagekit/example/` (เล็ก) หรือ `tools/pagekit/spec_phys_ch4/` (ครบ)

## ขั้นตอน
1. อ่านหนังสือ/คู่มือจากภาพหน้า PDF จริง (ไม่ใช่ OCR อย่างเดียว) จดเลขหน้าที่พิมพ์ในเล่ม
2. สร้างโฟลเดอร์ `tools/pagekit/spec_<ชื่อหน้า>/` ใส่ `content.js` (+ `labs.js` ถ้ามีห้องทดลอง)
3. `python3 tools/pagekit/build_page.py tools/pagekit/spec_<x> -o chemistry-xxx.html` (ใช้ `--check` เพื่อตรวจ spec อย่างเดียว) ชื่อไฟล์ต้องตรงกับ `PAGE.id`
4. QA อัตโนมัติ: `node tools/qa/qa_page.mjs chemistry-xxx.html` (ชุดตรวจนี้อีกเอเจนต์เขียนอยู่ อาจยังไม่มีในไม่กี่นาทีแรก ถ้าไม่มีให้ข้ามแล้วตรวจมือตามหัวข้อ "ที่ยังต้องตรวจเอง")
   (หน้าก่อน inject ไม่มี `__LAB_SUBMIT__`/`LabScore` จึงได้ SCORING FAIL ซึ่งเป็นเรื่องปกติ: kit ส่ง `LabScore.set/use` ให้ครบแล้ว ถ้าอยากพิสูจน์จริงให้คัดลอก `tools/inject_site_meta.py submit_module.js submit_config.json apple_theme.css` ไปโฟลเดอร์ชั่วคราวพร้อมหน้าแล้วรัน inject ที่นั่น ไม่ใช่ใน repo)
5. หน้าที่ build แล้วเป็นหน้า "ก่อน inject" ห้ามรัน `tools/inject_site_meta.py` เอง และห้ามใส่ marker `ls:/wm:/ap:/og:`; ถ้าเป็นหน้าเคมีใหม่ ให้แจ้งหัวหน้าเพิ่มรายการใน `M5_TITLES` ของ `inject_site_meta.py` (builder จะเทียบ `scoreId/scoreTitle` กับรายการนั้นให้เมื่อชื่อไฟล์ตรงแบบ)

## content.js: กำหนด `PAGE = {...}` (ข้อมูลล้วน HTML ได้เฉพาะ inline: p ul ol li b sub sup table.tw br details)
```js
PAGE = {
  id:'chemistry-m5-ch9', title:'เคมี ม.5 บทที่ 9 ...', short:'เคมี ม.5 บทที่ 9',   // id = ชื่อไฟล์ (คีย์ localStorage)
  scoreId:'...', scoreTitle:'...',     // ใส่เมื่อไม่ใช่ชื่อไฟล์แบบที่ inject รู้จัก (แบบที่รู้จัก builder เติมให้)
  accent:'#0f766e', accentDark:'#0b5a54', // accent: ปุ่ม/แท็บ ตัวขาวบนสีนี้ต้อง >= 4.5:1 (builder ตรวจให้)
  tabsLabel:'กิจกรรมในบทที่ 9',
  hero:{eyebrow:'...', h1:'...', lead:'...', notice:['<b>แบบจำลองเพื่อการศึกษา</b> ค่าที่สมมติเอง: ...']},
  footer:'แหล่งข้อมูล: คู่มือครู ... หน้า X–Y · ... ข้อความทั้งหมดเรียบเรียงใหม่โดยผู้จัดทำหน้า',
  tabs:[ {id:'9.1',kind:'activity',label:'ชื่อสั้น',title:'กิจกรรม 9.1 ...',sub:'คู่มือครู หน้า ..',run:true,html:'<div class="box">…จุดประสงค์ วิธีทำ…</div>'},
         {id:'sum',kind:'summary',label:'สรุปเนื้อหา',title:'สรุป',html:'...'}, {id:'ex',kind:'exercise',label:'แบบฝึกหัด'} ],
  read:{'9.1':{lead:'...',secs:[{h:'หัวข้อ',pg:'คู่มือครู หน้า 99–102',html:'<p>…</p>',q:['คำถามลองคิด','คำตอบ']}]}},
  quiz:{'9.1':{name:'9.1 แบบทดสอบ',items:[{q:'…',o:['ถูก','ผิด1','ผิด2'],a:0,w:'อธิบาย + (คู่มือ หน้า ..)'}]}},
  num:{xn:{name:'ฝ.1 คำนวณ',title:'..',items:[{q:'..',u:'g',a:50,tol:0.01,w:'..'}]}},
  grid:{xg:{name:'..',head:['รายการ','ผล'],rows:[['ก.',{sel:['เพิ่ม','ลด'],a:0}],['ข.',{n:2.5,tol:0.05,u:'mol'}]]}},
  forms:{'9.3':{id:'q',title:'แบบบันทึก',need:2,unit:'ปัจจัย',minChars:5,exportName:'activity-9-3.txt',exportHead:'ผลสืบค้น 9.3',
          groups:[{title:'ปัจจัย: ก',fields:[['a_e','เหตุการณ์'],['a_x','เพราะอะไร'],{id:'a_s',label:'แหล่งข้อมูล',opt:true}]}], reveal:[['ดูแนวคำตอบ','…']]}},
  ex:{title:'แบบฝึกหัด',sub:'..',note:'..',progress:true,export:{file:'exercise-9.txt',head:'สรุปบทที่ 9'},
      blocks:[{type:'quiz',set:'x1',h:'หัวข้อ',title:'..'},{type:'num',set:'xn'},{type:'grid',set:'xg'},{type:'fields',h:'ข้อเขียน',fields:[['w1','โจทย์']],reveal:[['ดูแนวคำตอบ','..']]},{type:'html',html:'..'}]}
};
```
- **tab.kind**: `activity` (หัวข้อ+html+ห้องทดลอง+ฟอร์ม+แบบทดสอบ นับเข้าความคืบหน้า) `summary` `exercise` `custom` (ใช้แต่ห้องทดลอง) · เสร็จเมื่อ: มีฟอร์มที่ตั้ง `need` = ฟอร์มผ่าน; ไม่งั้นมีแบบทดสอบ = ตอบครบ; บวก `run:true` = ต้องเรียก `run('id')` จากห้องทดลองด้วย; `done:'visit'` หรือ `track:false` ถ้าไม่ต้องการเงื่อนไข
- **แบบทดสอบ**: เขียนตัวเลือกถูกที่ `a` ตำแหน่งใดก็ได้ (นิยมเขียนไว้ตัวแรก) kit สลับตำแหน่งเอง กำหนดผลได้ ไม่เวียนวงจร/ไม่ซ้ำตำแหน่ง 3 ข้อติด; ต้องการกำหนดเองใส่ `perm:[ตำแหน่งเฉลยของแต่ละข้อ]`; ข้อที่ห้ามสลับ ("ถูกทุกข้อ", ตัวเลือกเรียงตามตัวเลข) ใส่ `keep:true`; ใช้ 2 ตัวเลือก (ถูก/ผิด) ได้ ตั้งชื่อ `name` ไม่เกิน 40 อักษร คะแนนเต็ม = จำนวนข้อ <= 100 รวมไม่เกิน 20 ส่วนต่อหน้า
- **forms**: กลุ่มที่นับ (`role:'count'` อัตโนมัติเมื่อมี `need`) ต้องกรอกช่องที่ไม่ `opt` ครบ >= `minChars`; กลุ่ม `role:'must'` ต้องผ่านเสมอ; `statusText:s=>…` (s={n,m,need,ok,mustOk}) ถ้าอยากเปลี่ยนข้อความสถานะ; ไม่มี `need` = ข้อเขียนล้วน (ไม่กระทบสถานะเสร็จ) ช่องข้อเขียนทุกช่องเป็น `<textarea id label[for]>` อัตโนมัติ

## labs.js: ห้องทดลองเฉพาะแท็บ
```js
lab('9.1', () => `<div class="lab"><h3>…</h3>${svg(280,150,'คำอธิบายภาพ',`<circle .../>`,{id:'sv'})}<button class="btn" id="go">เริ่ม</button></div>`,
(root) => {                                   // wire: ทำงานหลัง HTML ถูกใส่แล้ว root = #panel
  const loop = anim(dt => { /* อัปเดต */ return true /* false = จบ */ }, {el: root});
  $('#go').onclick = () => REDUCE ? finish() : loop.start();   // reduced-motion ต้องข้ามไปผลสุดท้าย
  function finish(){ run('9.1'); }            // ทำการทดลองครบ -> นับเป็น run
});
```
- ที่มีให้แล้ว (ห้ามประกาศซ้ำ): `$ $$ esc fmt REDUCE reduced dget dset ls qid state clean lab run anim svg fitSvg wireDraft wireRadio radioGroup fieldsHTML textOf revealHTML expHTML wireExp quizHTML wireQuiz numHTML wireNum markDone setLabel select`
- โค้ดชั้นนอกของ labs.js ต้องไม่แตะ DOM/เวลา/สุ่ม (builder รันเพื่อลงทะเบียนในกล่องจำลอง) ใช้ค่าคงที่แทน `Math.random` ให้ผลซ้ำได้
- **ต้อง** หยุดแอนิเมชัน/timer ทุกตัวผ่าน `anim()` หรือ `clean(fn)` ห้ามใช้ `requestAnimationFrame/setInterval` เปล่า ๆ
- SVG: ใช้ `svg(w,h,label,inner,{id})` (บังคับ role=img+aria-label) อัปเดตป้ายด้วย `setLabel(el,text)` เมื่อภาพเปลี่ยน; ออกแบบ viewBox กว้างราว 280–300 และตัวอักษร >= 12 ที่นี่ kit จะดันฟอนต์ให้ >= 11px บนหน้าจอ 375px ให้เอง (ถ้าข้อความทับกัน ให้แก้ผัง) หลังเขียน innerHTML ใส่ SVG ใหม่ ถ้าอยากให้ปรับทันทีเรียก `fitSvg(el)` · ตารางใน `<div class="tw">` ตาราง >= 3 คอลัมน์ใส่ `class="wide"`
- เวลาในแบบจำลองกับค่าที่สมมติเอง ต้องติดป้าย "แบบจำลองเพื่อการศึกษา/ค่าสมมติของผู้จัดทำหน้า" ในกล่อง lab
- ห้องทดลองที่มีคะแนนเอง: `ls('ชื่อไม่เกิน 40',ได้,เต็ม)` และแจ้งใน `PAGE.customParts:[{name,max}]` เพื่อให้ builder นับ/ตรวจ
- ข้อเขียนในห้องทดลองใช้ `fieldsHTML([[id,label,hint]])` + `wireExp` ได้ แต่ต้องตั้ง `hero.freeText:true`

## กติกาเนื้อหา (ผิด = ตีกลับ)
- เรียบเรียงด้วยคำพูดตัวเอง ห้ามคัดลอกประโยคจากหนังสือ/คู่มือ ห้ามอ้างว่า "ตรงกับหนังสือทุกคำ/ไม่ซ้ำกับหน้าอื่น"
- อ้างหน้าทุกส่วน (`pg`, `sub`, `w`, `footer`) ด้วยเลขหน้าที่พิมพ์ในเล่มและบอกเล่ม (คู่มือครู/หนังสือเรียน) ถ้าเลขหน้าเดาจาก OCR ให้บอกในฟุตเตอร์ว่า "โดยประมาณ"
- ค่าที่ผู้จัดทำสมมติ ข้อมูลนอกหนังสือ คำอธิบายเพิ่ม ต้องบอกชัดว่าเป็นของผู้จัดทำหน้า (ใน `w`, `html` หรือ `hero.notice`)
- ตัวเลขเฉลย/ผลตัวอย่างต้องตรวจกับ **ภาพหน้า PDF** (ข้อความ OCR เครื่องหมายถูก/ผิดและเลขยกกำลังมักหาย)
- ไม่เขียนข้อความบอกว่าหน้านี้ทำอะไรได้เอง: ประโยคฟีเจอร์ใน hero สร้างจาก config (แสดงเฉพาะที่มีจริง) ส่วน `hero.lead` ใช้บอกวิชา/บท
- สี accent ต้อง contrast >= 4.5:1 กับขาว (builder ตรวจ) อย่าตั้งสีอ่อน

## kit รับประกันให้แล้ว (ไม่ต้องทำ/ไม่ต้องตรวจซ้ำ)
โครงหน้า ธีม แท็บ (ลูกศร/Home/End, `#act-<id>`, roving tabindex) ความคืบหน้าและเครื่องหมายเสร็จใน localStorage (try/catch) · อ่านก่อนทดลอง (ปุ่มข้าม) · แบบทดสอบไม่ไฮไลต์ตัวเลือก + ตำแหน่งเฉลยสุ่มแบบกำหนดผลและตรวจรูปแบบ + ชุด 2 ตัวเลือก · ตัวเลข/ตาราง/ข้อเขียน/ส่งออก (`<pre>` สำรอง) · ร่างข้อเขียน · `LabScore.set/use` (use เรียกหลังสร้างแผง) · หมายเหตุข้อเขียนส่งเฉพาะแท็บที่เปิด · ปุ่มรีเซ็ตบอกว่าคะแนนไม่ถูกล้าง · ตาราง `.tw` ไม่ตัดครึ่ง + คำใบ้เลื่อน · `.fig svg` <= 560px · reduced-motion (CSS) · footer · ไม่ overflow ที่ 375px (เมื่อเนื้อหาของคุณไม่ดัน)

## ที่ยังต้องตรวจเอง
1. เนื้อหา เฉลย ตัวเลข เทียบ **ภาพหน้าต้นฉบับ** (ไม่ใช่แค่ข้อความ OCR) ทุกข้อ และเลขหน้าอ้างอิงถูก
2. ห้องทดลองของคุณ: ปุ่มทุกตัวทำงาน, reduced-motion ข้ามไปผลสุดท้าย, เปลี่ยนแท็บกลางแอนิเมชันแล้วไม่มี error, ข้อความทับกันใน SVG ที่ 375px, ค่าสมมติติดป้ายแล้ว
3. เปิดจริงในเบราว์เซอร์ที่ 375 และ 1280 ทุกแท็บ ดู console ไม่มี error (`K.audit()` ใน console คืนปัญหา SVG/ป้ายข้อเขียน/overflow ของแท็บที่เปิดอยู่; `K.positions()` คืนตำแหน่งเฉลยทุกชุดพร้อม `problem`)
4. ทดลองตอบถูกหมด/ผิดหมด ตรวจว่าคะแนนที่ส่งเข้า `LabScore.set` ตรงที่ตั้งใจ และเฉลยไม่ขัดกับเนื้อหาในแท็บ "อ่านก่อนทดลอง"
5. ไม่แตะหน้าอื่น/ไม่ regenerate หน้าเก่า รายงานสิ่งที่ยังไม่แน่ใจตามจริง
